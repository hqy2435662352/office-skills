# One SOP for updating an existing deck

Existing Deck Update will be one user-facing Workflow Skill following a normal office workflow: understand the request and materials, confirm only consequential ambiguity, modify the deck with OfficeCLI, render and inspect affected slides, repair clear defects, and deliver a new editable file with a concise change summary. Adapt, Refresh, and Review describe common work within that SOP rather than runtime modes that users or the Agent must classify explicitly.
