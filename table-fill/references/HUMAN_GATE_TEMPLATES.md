# Human Gate 模板

## 单次审核（Layer 3 后，合并 Layer 1-3 全部结果）

**议题**：同时审核展平结果、数据块分类、指标映射、格式约定、缺失表格提案。

**提问模板**：

```
Layer 1-3 完成。请审核：

### Layer 1: 展平结果
- 源文件: N 个展平 CSV，X 行 / Y 行
- 目标 PPTX: N 个 native table，M 个 OLE 嵌入
- ⚠️ Slide N 无表格

### Layer 2: 数据分类
- 数据块: Block1(主KPI,行X-Y) + Block2(观察指标,行A-B)
- 列分类: DIMENSION ×N, MEASURE_AGGREGABLE ×M, MEASURE_DERIVED ×K
- 增减率: 比率类用百分点差% 统一表达

### Layer 3: 指标映射
| Slide | 数据源 | 指标数 |
|-------|--------|--------|
| S5 | 源·Block1 | N 格 |
| S6_T3 | 源·Block2 | M 格 |

### ⚠️ 待决策
[Missing Table 提案 / OLE 处理方案 / 数据缺口]

请确认后进入 Layer 4 填充。
```

## 追溯表（必选 — 所有场景均需输出）

Layer 1 的展平 CSV 已为每行注入 `_source_row`（原始 Excel 行号）或 PPTX 坐标。
Layer 3 根据数据场景选择以下模板之一，嵌入映射表末尾。

### 场景 1：直接迁移（1:1 映射）

无聚合，每个目标单元格对应一个源行。用最简形式——抽查几个即可验证。

```markdown
## 追溯表：直接迁移

| 目标路径 | 目标含义 | 源坐标 | 源值 |
|---------|---------|--------|------|
| /Sheet0/C3 | 摩洛哥-FTC-客户名 | 源·行3,B列 | FTC |
| /Sheet0/D3 | 摩洛哥-FTC-1月 | 源·行3,G列 | 2774 |
| ... | ... | ... | ... |

**抽查建议**：随机选 3 个有数据的单元格，到源表对应行号核对。
```

### 场景 2：数据聚合（N:1 映射 — GROUP BY + SUM）⭐ 本次使用

多个源行汇聚到一个目标单元格。**源行号列表是追溯表的核心**——用户可手动加总验证。

```markdown
## 追溯表：数据聚合

**聚合逻辑**：`GROUP BY Country, Brand, Month → SUM(QTY/Sets)`

| 目标路径 | 目标含义 | 汇总量 | 来源行数 | 源行号 | 抽查验证 |
|---------|---------|--------|---------|--------|---------|
| /Sheet0/D14 | 摩洛哥-Fitco-1月 | 3,081 | 3条 | 行14,58,91 | 请用户手动加总验证 |
| /Sheet0/F6 | 埃及-Fresh-3月 | 20,000 | 4条 | 行33,45,67,89 | |
| /Sheet0/F3 | 利比亚-Fresh-3月 | 6,440 | 1条 | 行2 | (单条，无需加总) |
| /Sheet0/G3 | 利比亚-Fresh-4月 | 0 | — | (无源数据) | |
| ... | ... | ... | ... | ... | ... |

**抽查建议**：
1. 选 2-3 个多源行单元格，跳转到源表对应行号，手动加总对照
2. 检查"来源行数"为 0 的单元格——确认是确实无数据，而非遗漏
```

### 场景 3：数据清洗（带规则变换）

值经过规范化/过滤/补全后才填入。需要额外展示清洗规则列，让用户判断规则合理性。

```markdown
## 追溯表：数据清洗

| 目标路径 | 最终值 | 清洗规则 | 源行号 | 原始值 | 中间值 |
|---------|--------|---------|--------|--------|--------|
| /Sheet0/C5 | Kiowa | normalize_case() | 行22,45 | KIOWA, kiowa | Kiowa, Kiowa |
| /Sheet0/D8 | 6,440 | trim() + to_int() | 行2 | " 6,440 " | 6440 |
| /Sheet0/H5 | 0 | 空值→省略（不填入） | 行99 | (空) | — |

## 清洗决策记录

| 决策 | 判定 | 影响范围 | 建议 |
|-----|------|---------|------|
| Kiowa/KIOWA | 暂不合并（待业务确认） | 阿尔及利亚多 1 行 | 与业务确认后决定合并 |
| Active/shipped | 全部纳入（未过滤状态） | 若只算 shipped，总量可能减少 | 确认统计口径 |
```

## 禁止行为

- ❌ 在用户未确认的情况下开始 Layer 4
- ❌ 跳过此 Gate（layer_gate.py 会阻断）
- ❌ 将 Gate 拆分为多次提问（一次展示全部）
- ❌ 在映射表中省略追溯表——无论哪种数据场景，追溯表均为必选
