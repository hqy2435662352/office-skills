# Layer 3: 映射规则

## 映射开始前：扫描目标表已有格式

**在映射任何数据之前，必须先读目标表的已有数据来了解格式约定：**

1. 对目标表用 `officecli get --depth 2` 读取全文
2. 检查已预填的单元格（非空的数字/百分比）的格式：
   - 百分比差异是用 `%` 还是 `pp`？
   - 数字是千分位还是原始格式？
   - 小数位数是多少？
3. **填充数据必须与已有数据的格式约定一致。**

## 六种映射类型

| 类型 | 示例 | 处理 |
|------|------|------|
| **精确匹配** | `"变频销量"` → `"变频销量"` | 直接映射 |
| **缩写/子集** | `"主营业务收入"` → `"收入"` | 确认后映射 |
| **词序交换** | `"变频分体"` → `"分体变频"` | 确认后映射 |
| **同义词** | `"空调销量"` → `"总销量"` | 标注映射关系 |
| **确认排除** | `"定频窗机"` → 目标无此分类 | 标注排除原因 |
| **数据缺失** | 源无数据 → `"毛利率%"` | 标注为不可填充 |

## 衍生指标重算规则

- **AGGREGABLE 指标**：SUM()
- **DERIVED 指标**：从基础指标重新计算——SUM(分子)/SUM(分母)，**禁止 AVG()**
- **单位换算**：
  - 元 → 万元：÷10000
  - 元/套：不变（单位为内含属性）
  - 套 → 万套：÷10000

## 增减率格式约定

| 指标类型 | 增减率含义 | 格式 |
|---------|-----------|------|
| 数量/金额类（销量、收入、净利润） | 相对变化率 | `-37.58%` |
| 比率类（毛利率、占比） | 绝对百分点差 | `+4.06%`（**不用 pp**） |

**规则**：扫描目标表已有数据。如果"毛利同比"列已有 `%` 格式，则所有增减率统一使用 `%`。

## 映射表输出格式

Layer 3 产出两个文件：`{name}_映射表.md`（人类审查用）和 `{name}_batch.json`（机器执行用）。
batch.json 是 officecli 原生格式，由 SKILL.md 的 Layer 3 Pinned Constraints 约束其正确性。

### 映射表.md 格式

```markdown
# {name}_映射表

## Slide N - Table @id=M

| 目标单元格 | 源指标 | 源列 | 值 | 备注 |
|-----------|--------|------|-----|------|
| /slide[5]/table[@id=2]/tr[3]/tc[3] | 空调销量 | 累计实际 | 19.07 | 单位：万套 |
| /slide[5]/table[@id=2]/tr[3]/tc[7] | 空调销量 | 达成率 | 61.83% | 累计实际/累计目标 |

## 数据缺口

| 目标指标 | 原因 |
|---------|------|
| 毛利率 | 源数据为空 |
```
